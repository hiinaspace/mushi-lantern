# Material pass provenance

- `pine_bark_{diff,nor_gl}_2k.jpg`: [Poly Haven Pine Bark](https://polyhaven.com/a/pine_bark), by Dimitrios Savva, CC0. Higher resolution maps for the existing pine bark material.
- `lacquered_cherry_wood_{diff,nor_gl}_2k.jpg`: [Poly Haven Lacquered Cherry Wood](https://polyhaven.com/a/lacquered_cherry_wood), scanned by Jenelle van Heerden and processed by Rico Cilliers, CC0. The diffuse and OpenGL normal maps tint the staff shaft and shrine gate/altar.

Downloaded from Poly Haven's official `dl.polyhaven.org` 2K JPEG paths on 2026-09-27. Source textures are shared between instances and imported with mipmaps. The coated pine comparison and unused roughness map were removed from the build. The shrine foundation now uses the 1K CC0 Rock Surface diffuse and OpenGL normal pair documented in `shrine_rock_surface/PROVENANCE.md`. The shrine fittings reuse the existing 1K brass maps from `assets/lantern/st-brass/`; no new brass textures were added.
