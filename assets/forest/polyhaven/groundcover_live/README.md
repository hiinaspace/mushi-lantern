# Runtime ground cover

`weed_plant_02.glb` and `shrub_02.glb` are the selected, texture-bundled
Poly Haven CC0 derivatives from the committed ground-cover audition. Their
source 1K glTF bundles, reduction settings, and links are documented in
`../groundcover_audition/README.md`. Runtime scatter uses one representative
mesh from each bundle, with Terrain3D instancing and distance culling.
